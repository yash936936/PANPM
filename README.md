# PANPM

PANPM (Parkinson's Active Neuroimaging and Progression Model) is a proposed research system for studying Parkinson's disease using PPMI MRI, longitudinal clinical assessments, genetically informed regional priors and reinforcement learning for adaptive MRI-region inspection.

**Current state:** documentation and engineering scaffold only. PPMI data access, MRI modality coverage, preprocessing, models and RL training have not yet been completed. This repository must not be presented as a working diagnostic or clinical system.

Start with [`context.md`](context.md), then read [`docs/status.md`](docs/status.md), [`docs/architecture.md`](docs/architecture.md) and [`docs/phases.md`](docs/phases.md).

The initial research build starts with the PPMI data inventory. It does not assume that every participant has T1, DTI, neuromelanin MRI, QSM or fMRI. MRI modalities will be enabled only after participant-level coverage and sequence metadata are verified.
